# Roadmap — funciones estilo Clio

## Hecho
- [x] Plantillas de procesos, fechas relativas, carga en un clic, documento detonante
- [x] Tablero Kanban de fases (arrastrar, días en fase, plantilla automática al entrar a una fase)
- [x] Campos personalizados por materia (texto, número, fecha, casilla), edición en línea en el expediente

## Hecho (tanda 2)
- [x] Tareas: subtareas, dependencias entre tareas (se mueven solas), asignar a equipo
- [x] Vistas guardadas de filtros en expedientes
- [x] Avisos dentro de la app (campana): recordatorios de eventos, plazos por vencer, cuotas vencidas, mensajes del portal, citas nuevas
- [x] Calendario: recordatorios por defecto según tipo de evento; agenda pública de citas para clientes
- [x] Cronómetros múltiples de tiempo ligados a expediente/tarea/documento; facturar horas
- [x] Facturación: planes de cuotas, saldo vencido y recordatorios (portal + WhatsApp), facturación masiva
- [x] Documentos: vista previa, versiones, enlaces seguros que caducan
- [x] Portal del cliente (enlace mágico, ver fase del caso, subir documentos, mensajes, saldo)
- [x] Mensajes masivos a clientes (al portal + lista de correos)
- [x] Reportes: tasa de cobro, saldos, horas, exportar CSV/PDF
- [x] Asistente IA: resumir documentos y preguntar sobre varios archivos con citas
- [x] Respaldo/exportación completa de datos del estudio

## Bloqueado
- Envío automático por correo (recordatorios, reportes programados): requiere un dominio de correo propio
- Pagos con tarjeta: requiere elegir proveedor
- Sincronizar Google/Outlook/Zoom: requiere conexión de cuenta
- Firma electrónica: requiere proveedor real
